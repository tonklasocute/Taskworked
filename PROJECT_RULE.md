# Rules

Always generate production-ready code.

Never generate demo code.

Never hardcode values.

Always separate UI and Business Logic.

Always use TypeScript.

Always create reusable components.

Always create reusable hooks.

Always use Clean Architecture.

Always use Repository Pattern.

Always use Service Layer.

Always create DTO.

Always validate request.

Always use PostgreSQL.

Always use Redis cache.

Always use Docker.

Always generate API documentation.

Always write clean commit messages.

Always keep the project scalable.

Every feature must include

- UI
- API
- Database
- Validation
- Permission
- Unit Test
